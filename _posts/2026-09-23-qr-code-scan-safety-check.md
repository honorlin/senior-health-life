## 30秒看懂

QR Code 只是把文字、網址或交易資料藏進方格圖案，方便手機讀取；它本身不是政府認證，也不是安全標章。安全的店家、展館或政府服務會用 QR Code，詐騙者也能把可疑網址、假客服或付款要求做成幾乎一模一樣的方格碼。

內政部警政署刑事警察局提醒，近期假網拍話術會要求民眾開啟視訊、分享畫面，甚至翻拍付款碼或無卡提款 QR Code。移民署的防詐資訊也指出，假客服常用「訂單重複」「持續扣款」「帳戶異常」製造時間壓力，再要求操作網路銀行或 ATM。

所以重點不是「以後都不要掃」，而是每次多做六件事：先看來源、檢查有沒有覆蓋貼紙、讀清楚手機預覽、分辨碼的用途、不照陌生人指示操作，遇到催促就離開原對話，自己找官方管道查證。

## 實用內容

### 一、先問「這個碼從哪裡來」，不要只看印得像不像

掃描前先停三秒，看看 QR Code 出現在哪裡。店內固定立牌、官方帳單、機關櫃檯說明與朋友轉傳的截圖，可信程度並不相同。即使版面有熟悉的名稱、顏色或標誌，也不能只靠外觀判斷，因為圖片與文字都可以仿製。

如果 QR Code 來自簡訊、陌生社群帳號、未預期的電子郵件，或對方主動說要幫你「解除扣款」「完成認證」，先不要掃。真的需要處理訂單時，自己開啟原本使用的官方 App，或從已收藏的官網入口查詢，不要沿用訊息裡附的連結、電話或客服帳號。

在餐廳、停車場、繳費機或公告欄看到實體 QR Code，也先看紙張邊緣。若像是後貼的貼紙、遮住原碼、翹起、位置突兀，或旁邊說明與掃描後內容不一致，先請現場工作人員確認。

### 二、掃描不等於立刻開啟，先讀手機顯示的預覽

多數手機相機讀到 QR Code 後，會先顯示網址、文字或動作提示。不要一看到通知就直接按下；先看它說的是開網頁、加入聯絡人、連接 Wi-Fi，還是進入付款畫面。

網址要從網域名稱看起，而不是只看頁面標題。字母被替換、多一個連字號、拼字很接近、網址縮得看不出目的地，或網域與現場機構完全無關，都值得停下來。手機畫面太小看不清楚時，不必勉強辨認；可以取消，改由官方 App 或自行輸入已知網址。

保安警察第一總隊轉載的資安趨勢資料指出，QR Code 釣魚會把連結藏進圖案，讓使用者改到手機開啟，也可能使完整網址較不容易被注意。養成「先看預覽，再決定是否開啟」的習慣，比背下每一種新話術更實用。

### 三、看清楚這是「資訊碼」還是「交易碼」

有些 QR Code 只帶你到菜單、活動介紹或官方表單；有些則會啟動付款、轉帳或無卡提款流程。兩者外表相似，後果卻不同。只要畫面出現金額、收款方、付款、提款、授權、驗證碼或金融帳戶，就先把它當成交易處理，逐項確認後才繼續。

自己的付款碼、收款碼與無卡提款碼也不能混為一談。刑事局指出，付款碼或無卡提款 QR Code 外流，可能等同把支付或提領權限交給他人。不要截圖轉傳、不要讓陌生人翻拍，也不要在視訊或螢幕共享時打開。對方若說「只是確認身分，不會扣款」，仍應停止操作。

### 四、遇到催促、保密或遠端指揮，先離開原本的對話

詐騙常利用急迫感讓人來不及核對，例如「現在不處理會一直扣款」「超過幾分鐘就失效」「不能掛電話」。此時不要和對方辯論，也不要一邊通話一邊操作手機。先掛斷、關閉視訊與螢幕共享，離開對方提供的網頁。

接著用另一條路查證：自己開官方 App、從帳單背面找客服電話，或請信任的家人一起看。官方客服是否真的來電、訂單是否異常，都應在原服務的正式管道確認。不要請原本那位「客服」轉接，因為整段通話可能都由同一群人控制。

### 五、開網頁後先不輸入資料，也不下載陌生檔案

掃描後如果頁面要求輸入身分證號、帳號密碼、信用卡資料、簡訊驗證碼，或下載不熟悉的 App、描述檔與檔案，先關閉頁面。單憑鎖頭圖示或 `https` 不能證明對方就是正牌機構，它只表示連線有加密。

如果只是誤開頁面，但沒有輸入資料、下載檔案或同意付款，可以先關閉分頁，再從官方入口確認。若手機跳出相機、通訊錄、簡訊、定位或螢幕分享權限，而服務用途說不清楚，也先拒絕。不要為了「完成掃碼」一路按同意。

### 六、已經提供資料或付款，就保存畫面並直接找正式單位

發現不對勁時，先停止與對方聯絡，不再按照後續訊息操作。保留可疑帳號、網址、對話時間、交易畫面與金額等資料；不要因為慌張而刪除全部紀錄，也不要再把驗證碼或付款碼傳給任何自稱協助的人。

若已涉及金融資料或款項，請用金融卡、存摺或官方網站上的電話，直接聯絡自己的銀行或支付機構，並撥打 165 反詐騙諮詢專線。處理方式要由正式單位依實際交易狀況說明，本文不能保證款項一定能攔回。

## 今天可以怎麼做

1. 打開手機相機，找一個自己熟悉且可信的 QR Code，練習只看預覽、不立刻開啟。
2. 和家人約定：任何人要求分享付款碼、無卡提款碼、驗證碼或手機畫面，一律先停止。
3. 把常用銀行、購物與繳費服務的官方 App 放在固定位置，需要查詢時自己開啟。
4. 在公共場所掃碼前，看一眼是否有覆蓋貼紙、翹起邊緣，並比對旁邊的用途說明。
5. 看見金額、收款方或授權按鈕時，停下來逐項核對，不因後面有人排隊就匆忙確認。
6. 將 165 記在紙本聯絡卡或手機聯絡人；有疑問時改走正式管道查證。

## 哪些情況要先詢問專業人員

如果掃描後出現不認識的收款方、已送出付款、提供金融資料、分享付款碼或無卡提款碼，請立即停止操作，直接聯絡銀行或支付機構的官方客服，並向 165 詢問。若帳戶或信用卡 App 顯示不明交易，也以金融機構實際紀錄為準，不要相信陌生客服傳來的截圖。

手機若因掃碼後開始反覆跳出廣告、出現不明 App、要求安裝描述檔，或你不確定曾經允許哪些權限，可請原廠門市、電信業者或可信賴的資訊專業人員協助檢查。不要讓來路不明的人遠端控制手機，也不要交出解鎖密碼。

本文提供一般數位安全資訊，無法判定每一個 QR Code 或個別交易是否為詐騙。詐騙手法會變動，遇到實際案件時，應以警政、金融機構及服務業者當下的正式說明為準。
